# SMC Premium/Discount Confluence Engine — v17.60 Changelog

**Release:** v17.60 — *Trader HUD Redesign*
**Date:** 2026-06-06
**Base version:** v17.59.1
**Scope:** Display layer only. **No** changes to signal generation, alert logic, or the state machine.

---

## Summary

v17.60 is a **pure HUD/UX redesign**. It declutters the on-chart Heads-Up Display by
simplifying the Guardian readout, replacing the verbose "Trade" row with a focused
MSS status row, merging the standalone "Action" row into Guardian, and adding a
manually-driven High-Impact News row. Trading behaviour is **byte-for-byte identical**
to v17.59.1.

---

## Changes

### UI — Trader HUD redesign
- **Guardian row simplified & merged with Action.** The Guardian row (Row 8) now shows
  a compact `DIRECTION | ACTION` token instead of the long descriptive label.
  - Direction tokens: `BUY`, `SELL`, `CONFLICT`, `STANDBY`, `REVERSAL`.
  - Action tokens: `EXECUTE`, `STANDBY`, `—`.
  - Examples: `BUY | EXECUTE`, `SELL | STANDBY`, `STANDBY | —`, `CONFLICT | —`.
  - Direction is derived from the already-finalized `guardianDisplayCode`; `EXECUTE`
    appears only when the existing stage gate already reports `EXECUTION READY`.
  - Existing risk-escalated colour coding (`guardian_hud_color`) is preserved.
- **"Trade" row → "MSS" row (Row 11).** Replaced the Trade Context row with a focused
  Market-Structure-Shift status:
  - `MSS WAITING LONG` / `MSS ACTIVE LONG` when `sniperLong` or `tier2LongFire` is active.
  - `MSS WAITING SHORT` / `MSS ACTIVE SHORT` when `sniperShort` or `tier2ShortFire` is active.
  - `—` otherwise.
  - "ACTIVE" vs "WAITING" mirrors the existing `mssState`/`mssDir` machine (read-only).
  - Existing Trade-row colour logic retained.
- **Removed the standalone "Action" row.** Its guidance is now folded into Guardian.
  Rows below it shifted up by one so the table has no blank gap; the optional
  Debug (21–26), Sequence (27–29) and Trend-Override (30–33) rows keep their indices.

### UI — HUD default text size set to normal
- `f_setCell` and `f_setHdrCell` render at `size.normal` (verified/locked for v17.60).
- `f_setDbgCell` intentionally left at `size.tiny` to keep diagnostic rows compact.

### Feature — High-Impact News row (manual)
- Two new inputs (group **📰 High-Impact News (v17.60)**):
  - `High-Impact News (manual)` — free-text event description (defval `""`).
  - `News Severity (0=none, 1=low, 2=med, 3=high)` — integer 0–3 (defval `0`).
- New "News" HUD row (Row 20), placed in the always-visible block before the
  optional Debug rows.
- Display: shows the entered text, or `No high-impact news` when blank.
- Colour by severity: `3 = red`, `2 = orange`, `1 = yellow`, `0 / blank = gray`
  (greyed-out = inactive/stale).
- **Automation note:** Pine Script cannot fetch external APIs or economic-calendar
  data, so this field is updated manually. See `v17.60_NEWS_README.md` for automation
  options (external companion service, browser extension, etc.).

### Non-functional guarantees
- No changes to signal generation (`sniperLong`, `tier2LongFire`, `sniperShort`,
  `tier2ShortFire`, etc.).
- No changes to alert firing conditions or alert message content.
- No changes to the state machine (The Gate), sequence validation, BOS detection,
  liquidity sweeps, displacement, or any calculations.
- All existing alert state variables (`last_alert_time`, `last_alert_type`, …) and the
  30-minute alert-staleness logic are preserved unchanged.
