## What Changed

### 🔄 Alert Format (Breaking Change)

**Old (v17.25)** — plot-based `alertcondition()`:
```json
{
  "type": "sniper_long",
  "symbol": "{{ticker}}",
  "entry_price": {{plot_0}},
  "stop_loss": {{plot_1}},
  "take_profit": {{plot_2}},
  "version": "v17.25"
}
```

**New (v17.54)** — dynamic `alert()` JSON:
```json
{
  "version": "v17.54",
  "alert": "A_PLUS_SNIPER_BUY",
  "symbol": "{{ticker}}",
  "timeframe": "{{interval}}",
  "price": "{{close}}",
  "message": "v17.54 A+ SNIPER BUY - Aligned with Trend. Target 1:3 RR."
}
```

### 🧠 Backend Intelligence

The OIE processor now handles **three alert generations**:

1. **v17.54** (new): `alert` field with `A_PLUS_SNIPER_BUY`, `RETRACE_LONG`, etc.
   - Price from `{{close}}`, SL/TP auto-calculated (20 pips sniper / 30 pips retrace, 1:3 RR)
2. **v17.25** (legacy): `type` field with `sniper_long`, `retrace_short`, etc.
   - Prices from `{{plot_X}}` placeholders
3. **v17.14** and earlier: Legacy compact format
